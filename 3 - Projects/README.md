# C++ Learning & Projects

Welcome to my C++ learning repository!

## 🚀 How to Run the Projects

### Requirements
- Git
- C++ Compiler (G++)
- Linux / GitHub Codespaces

### Run Projects Menu

1. Clone the repository:

```bash
git clone https://github.com/znibimahmod-ship-it/CPP-Learning.git
```

2. Navigate to the Projects folder:

```bash
cd CPP-Learning/"3 - Projects"
```

3. Give execution permission:

```bash
chmod +x menu.sh
```

4. Launch the menu:

```bash
./menu.sh
```

### Available Projects

1. Rock Paper Scissors
2. Math Quiz Game

Choose your preferred project from the menu and enjoy!

---

**Note:** The projects support Windows and Linux where applicable. GitHub Codespaces provides a Linux environment with G++.
